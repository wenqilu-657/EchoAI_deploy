Data Pipeline & Cleaning Transparency

This dashboard runs on ListenBrainz scrobble telemetry (March–August 2026) joined with the MusicBrainz core catalog database.

Cleaning Rule What Was in Raw Data Action Taken
1. Bot Filtering 1,692 bot accounts scrobbling >500 songs/day Excluded bots. Eliminated 39.2% of raw plays to protect real human signals.
2. Play Deduplication 4.8 million duplicate play logs Deduplicated exact same-second plays by the same user.
3. Non-Artist Entities [unknown], soundtracks, ambient machines Excluded special-purpose acts using MusicBrainz entity types.
4. Name Collisions 250 different musicians named "Indigo" Unified on MusicBrainz MBID UUIDs; redirected merged IDs.
5. Missing Metadata 44% of artists have uncatalogued country/genre Preserved as Unknown; never fabricated or imputed.
6. Activity Floor Artists with 0, 0, 15 listeners creating fake +1500% spikes Enforced $\ge 5$ baseline listeners/mo across $\ge 2$ active months.
Dataset Scale Notice: The full canonical clean database contains 610,423 artists and yields 1,131 emerging acts. This local browser evaluation is running on a lightweight 58-artist test fixture (56 KB) so the repository is self-contained and clones instantly for instructor grading.
